# FriendBPSort (2.0.0)
Six buttons beside the friends board. Sorting applies across online and offline players together. (1.0.0)

- Name: A–Z / Z–A.
- BP: highest / lowest.
- Friend Added: newest / oldest known addition.
- Recently Played: most recent / least recent encounter.

Requires the MatchInfo Mod V (2.0.0)

- WLR: most wins → fewest wins → most losses → fewest losses.
- Total Matches: most / fewest (wins + losses against each opponent).

## Optional MatchInfo compatibility - MatchInfo mod By UlvakSkillz (2.0.0)
Reads UserData/MatchInfo/MatchInfo.txt using MatchInfo match data

MatchInfo is NOT a required dependency.

Mod on Thunderstore https://thunderstore.io/c/rumble/p/UlvakSkillz/MatchInfo

## Existing limitations
Historical friend-added dates are unavailable. Existing friends establish a baseline; newly observed additions receive timestamps. Recently Played records encounters, not necessarily completed matches. BP appears when the game loads that player's profile normally.

## Install
Close RUMBLE and replace the previous FriendBPSort.dll in RUMBLE/Mods with this DLL. Requires MelonLoader;

## Per-player value boxes (2.0.0)
Displayed to the right of each user is the numerical data sorted
