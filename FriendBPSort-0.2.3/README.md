# FriendBPSort 1.0.0

Four buttons added to the right of the Friend Board that allow you to catagorize all of your friends.

- SORT A–Z: alphabetical names, ignoring color/formatting tags.
- SORT BY BP: highest known BP first.
- FRIEND ADDED: most recently observed new friendship first.
- RECENTLY PLAYED: most recently-met encounter.

Selecting a mode returns the list to the first page. The choice and locally observed dates are saved in MelonLoader preferences.
